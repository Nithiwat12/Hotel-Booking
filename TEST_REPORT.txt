Important:
The uploaded .env did not contain a real Neon password; it contained a placeholder.
Therefore a live authenticated query to the user's Neon project cannot be completed from this package until the real password is entered.

Before running in XAMPP:
1. Open .env
2. Replace YOUR_NEON_PASSWORD with the real Neon password from Neon Console > Connect.
3. Put the folder in C:\xampp\htdocs\hotel
4. Start Apache.
5. Open http://localhost/hotel/main.php

If pdo_pgsql is disabled, enable extension=pdo_pgsql in XAMPP php.ini and restart Apache.
